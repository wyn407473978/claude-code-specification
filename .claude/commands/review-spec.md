# Review Spec

请以个人开发者长期维护项目的角度审查本仓库中的 Claude Code 规范文档。

重点检查：

1. 规范是否清晰、可执行，Claude Code 是否能按它稳定行动。
2. 是否存在过度工程化、一刀切、对小项目不友好的要求。
3. 是否存在相互冲突的规则，例如 Git、测试、提交、技术栈默认值。
4. 是否遗漏安全、隐私、迁移、验证、回滚、交付报告等关键约束。
5. 是否有过期、重复、空泛、不可验证的表述。
6. 是否需要把长期项目、高风险项目、Demo/个人工具区别对待。

输出要求：

- 先列出高优先级问题，再列中低优先级建议。
- 每条建议说明影响、原因和推荐改法。
- 如果建议修改文件，给出具体文件路径和章节位置。
- 不要只泛泛评价“不错”或“需要优化”。
